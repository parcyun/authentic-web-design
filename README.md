# authentic-web-design

웹 UI에서 반복되는 AI-generated feel을 줄이고, 목적·브랜드·사용자 행동이 드러나는 디자인을 만들기 위한 독립 Codex 스킬이다.

## 무엇을 해결하는가

- 보라색 그라디언트, 이모지 아이콘, 반복 카드처럼 흔한 AI 디자인 패턴을 제거한다.
- 색 온도, 타이포그래피, 8pt 간격, 정보 위계를 하나의 시스템으로 맞춘다.
- 장식보다 실제 데이터·핵심 행동·접근 가능한 상태를 우선한다.
- 디자인 전 `pre-design` 방향 확정과 디자인 후 자기 검토를 연결한다.

## 사용 시점

다음 작업에 사용한다.

- 웹페이지, 랜딩페이지, 대시보드, UI 컴포넌트 디자인
- “AI 느낌을 줄여줘”, “더 프로페셔널하게”, “감각적으로 다듬어줘” 요청
- 컴포넌트 라이브러리·아이콘·타이포그래피 선택
- 기존 화면의 색상, 간격, 카드, 버튼, 애니메이션 개선

## 작업 순서

1. `pre-design`으로 매체·대상·톤·브랜드·규모·제약과 핵심 행동을 확정한다.
2. 이 스킬의 안티패턴과 시각 원칙으로 구현 방향을 정한다.
3. 기존 브랜드 토큰과 컴포넌트를 우선 재사용한다.
4. 실제 데이터, 반응형 레이아웃, focus 상태, reduced motion을 확인한다.
5. 결과물에서 불필요한 장식과 반복을 제거하고 실제 UI에서 검증한다.

자세한 규칙과 체크리스트는 [`SKILL.md`](./SKILL.md)에 있다.

## 다른 스킬과의 관계

`pre-design`은 구현 전 방향을 고정하는 사전 단계이고, `authentic-web-design`은 실제 시각·인터랙션 설계 중 적용하는 기준이다. 브랜드 스킬(`parcyun-studio`, `MDBF` 등)이 지정되면 해당 브랜드의 토큰과 규칙을 우선한다.
